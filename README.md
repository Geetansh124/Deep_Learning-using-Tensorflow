# Deep Learning Repository

Welcome to the Deep Learning repository! This repository contains a comprehensive collection of Jupyter Notebooks, datasets, and projects covering fundamental to advanced Deep Learning concepts and architectures.

## Structure

The repository is organized into several main directories under `Deep Learning/`, each focusing on a specific neural network architecture or concept:

### 1. Perceptron (`Deep Learning/Perceptron/`)
- **Concepts**: Gradient Descent, basic Perceptron implementation.
- **Notebooks**: `Gradient_decent.ipynb`, `perceptron.ipynb`, `perceptorn-2.ipynb`.

### 2. Artificial Neural Networks (ANN) (`Deep Learning/ANN/`)
- **Concepts**: Backpropagation, Memoization, Neural Network Performance Improvement, Vanishing Gradient Problem.
- **Projects/Notebooks**:
  - Credit Card Customer Churn Prediction
  - MNIST Classification
  - Graduate Admission Prediction

### 3. Convolutional Neural Networks (CNN) (`Deep Learning/CNN/`)
- **Concepts**: Padding & Strides, Data Augmentation, CNN Filters and Feature Maps, Pooling Layers, CNN Architecture (LeNet-5).
- **Projects/Notebooks**:
  - Image Classification Model (Cats vs Dogs)
  - CNN Visualizing

### 4. Recurrent Neural Networks (RNN) (`Deep Learning/RNN/`)
- **Concepts**: RNN Architecture, LSTM, Bidirectional RNN, Deep RNN.
- **Projects/Notebooks**:
  - Next Word Predictor
  - RNN Sentiment Analysis (Simple RNN, Embedding)

## Getting Started

### Prerequisites
To run the notebooks in this repository, you will need to have Python installed along with several key data science and machine learning libraries:
- Python 3.x
- Jupyter Notebook or JupyterLab
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

### Installation
Clone the repository and install the required dependencies (you can use `pip` or `conda`):

```bash
git clone <repository_url>
cd <repository_name>
```

Launch Jupyter Notebook to explore the files:
```bash
jupyter notebook
```
